HERO.IO App Manager

This is an interactive overview of the HERO.IO App Manager, a responsive web application designed to showcase, install, manage, and uninstall software. Explore the features and try a live demo below.

✨ Features

Core functionalities of the application.

App Installation & Management

Users can "install" apps, saving data to browser local storage. The dedicated Installation Page lists all installed applications.

App Uninstallation

Apps can be permanently removed from the installed list, immediately updating both the UI and local storage for persistent changes.

Dynamic Sorting

Users can sort the list of installed apps dynamically by size (low-to-high or high-to-low) via a simple dropdown control.

Responsive Layout

The layout is designed to be fully responsive for mobile, tablet, and desktop views, built with Tailwind CSS.

Robust Error Handling

Includes custom pages for generic 404 routing errors and specific "App Not Found" scenarios to guide the user.

💻 Component Breakdown

The key building blocks of the application.

Installation.jsx

The main screen for managing installed apps. Fetches data from `localStorage`, handles uninstall logic, and features size-based sorting.

AppDetails.jsx

Shows detailed information for a single app. Used for displaying rich content and handling the initial installation action.

Footer.jsx

A persistent footer with logo, copyright, and external social media links.

ErrorPage.jsx

Full-page handler for generic route errors (404s), directing users back to the homepage.

NotFound.jsx

Component for specific "App not found" cases, used when an app ID is invalid.
